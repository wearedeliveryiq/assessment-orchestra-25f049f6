## Delivery sequence

| Stage | Intended outcome | Exit evidence |
|---|---|---|
| Sprint 1 | Platform foundation | Brand, design system, navigation and platform structure |
| Sprint 2 | Intelligence runtime foundation | Assessment runtime, evidence model and traceable inputs |
| Sprint 3 | Enterprise assessment and improvement experience | Explainable analysis, insight, recommendations and roadmap |
| Later release | Delivery DNA public experience | Controlled public slice assembled from shared capabilities |
| Later release | Knowledge Pack Studio and library | Governed specialist diagnostics |
| Later release | TeamMate Framework and first TeamMates | Auditable execution support with measurable outcomes |

## Roadmap rules

- Delivery DNA is assembled from the platform, not rebuilt separately.
- DIQ-202 is a release gate for material changes.
- Detailed delivery activity belongs in the controlled sprint playbooks.
- Release evidence must show alignment with DIQ-002.
